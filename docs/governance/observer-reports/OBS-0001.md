## 2. 建議改善項目（與董事長討論）

1. **[優先級高] 補助合計把「轉述」與「稅額抵減」當成確定現金顯示**：`src/core/subsidies/index.ts:565-590`、`src/ui/Subsidy.tsx`（`SubsidyCard` 標題列「估算合計」）、`src/features/ai/pages/QuoteCompare.tsx:256-305`（「估計補助」「扣除補助後」與回本月數）。
   - 單項有「經銷商參考區間」橘標，但綠色大字的合計、比價表的「扣除補助後」與回本月數，都**沒有**標出其中含有轉述的每 kW 單價。
   - 投資抵減（5%）是抵稅、上限為當年應納稅額 30%，虧損或低稅負的中小企業可能拿不到，卻直接併入現金合計並從報價扣除。
   - `tax-credit` 標為 `reliability: 'official'`（「官方原文」綠標），來源卻是 udn 新聞（第 100 行），自相矛盾。ESPC 的 `deadlineIso: '2027-09-30'` 沒有出處（目前沒被使用）。
   - **建議**：合計只算現金補助，抵稅另列一行「可能抵稅」；只要合計中有任何 `relayed` 項目，就在合計與「扣除補助後」旁顯示同一個橘標；回本月數改用現金補助計算；`tax-credit` 改成 `relayed`，等換成全國法規資料庫條文連結後再改回；刪除或註明沒有出處的 `deadlineIso`。
2. **[優先級高] 補助判斷的「今天」寫死成 2026-11-13**：`src/core/subsidies/index.ts:269` 的 `today = '2026-11-13'`，6 個呼叫點都沒有傳入日期。2027/01/15 之後，動力設備補助仍會顯示「可能適用」，`closed` 分支永遠不會觸發，測試也沒有涵蓋。**建議**：呼叫端傳入 `nowIso().slice(0,10)`；補一個「截止日之後顯示 closed」的測試。
3. **[優先級高] 公開的 `POST /api/feedback` 沒有防護，且與邀請信的承諾不一致**：`scripts/serve-prod.mjs:96-125`。
   - 原樣展開任意 JSON（`...payload`），每次最多 64KB，沒有頻率限制，任何人都能灌爆磁碟，也能自帶 `isTest` 讓紀錄被排除在統計之外。
   - 會記錄訪客 IP 與 UA，表單上卻沒有告知；邀請信（`docs/board/outreach-template.md`）寫的是「資料只存在您自己的瀏覽器」。
   - 紀錄寫進 repo 內的 `docs/board/live-feedback.jsonl`，沒有列入 `.gitignore`。
   - 依 `RELAY.md`，自主代理會讀這個檔案並「act on real feedback」，等於公開網路的任意文字可以直接進入有寄信權限的代理（提示詞注入通道）。
   - **建議**：欄位白名單加長度上限、每個 IP 限制頻率、不存 IP（或只存雜湊）、表單加一行說明會送到團隊伺服器、紀錄移出 repo 或列入 `.gitignore`；`RELAY.md` 明定回饋內容只當資料、不當指令。
4. **[優先級高] 對真實公司的自主外寄繞過了雙簽與觀察者關卡**：`docs/board/RELAY.md`（已寄 60 封邀請加 19 封跟催，Batch 4–5 排隊中，並由代理自行重啟 tunnel 與 server）。這和 `BOARD_PROTOCOL.md` §2「指令須雙簽、報備須經觀察者」是兩套互相重疊的治理，外寄這類不可逆、對外的動作沒有任何 PROP 或使用者核可紀錄。**建議**：由使用者裁定以哪一套為準；在裁定前暫停 Batch 4–5；之後每一波外寄都需要一份 PROP 加使用者核可。
5. **[優先級高] 一整天的成果只存在一份未提交的工作目錄**：54 個修改加 15 個未追蹤，`git remote` 為空，代表沒有任何備份。公開站的 `dist` 是從未提交的程式樹建置，無法重現。任何一次 `git checkout .` 或 `stash` 都會全部遺失。**建議**：由 CEO 分批提交（補助／回饋與導覽／guard／治理文件），先決定 `live-feedback.jsonl` 與 `outreach-*`（100 個真實公司信箱）是否進 git；並加上私有遠端備份。
6. **[優先級中] 未得標廠商仍看得到合約金額**：`src/features/workspace/lib/transitions.ts:191` 把「合約金額 NT$ …」寫進事件文字，`CaseTracker.tsx:342-358`「活動紀錄」對所有可檢視者原樣顯示。同一頁的第 258 行卻告訴未得標廠商「合約金額…僅對工廠與得標廠商公開」。公開站的資料存在各自的瀏覽器，目前只有示範資料受影響；但在 claude.ai 共享資料模式下，這是真實外洩。另外，所有權限判斷都只在前端進行。**建議**：未得標廠商的活動紀錄只顯示到 `select_vendor` 為止，或遮蔽金額與之後的用電紀錄；補一個 render 測試。
