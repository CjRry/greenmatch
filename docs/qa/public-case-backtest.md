## 來源

全部出自 **經濟部能源署 節能標竿網・114 年度節能標竿獎「標竿案例」**（政府資料開放平台資料集 22245「節能成功案例檢索」的關聯網站）。案例頁只有案例編號，不寫公司名稱；我們沿用案例編號，不去查是哪家公司。
每頁頁首有四個欄位：節省電力（千度）、節省費用（仟元/年）、投資金額（仟元）、回收年限（年）。內文若有更精確的度數就用內文，並在 `section` 欄註明。

## 回測方法

1. 用的是報價比價頁同一段程式 `computeInteractiveRoi`（本輪從 `features/ai/lib/quoteParser.ts` 搬到 `src/core/domain/roi.ts`，原檔重新匯出，行為不變）。
2. 輸入＝案例的「改善前」條件：投資金額、年節電度數；電價與運轉時數用工廠還沒填電費時的平台預設（4.2 元/度、16 小時 × 300 天，時數倍率 = 1）。
3. 來源的回收年限＝投資÷年省電費（10 筆都驗算過，差 ≤ 0.05 年），**沒有扣補助**，所以跟平台的「扣補助前」回本比較。10 筆都沒寫補助金額，欄位標「來源未揭露」，平台不估。
4. 誤差＝平台試算回本 − 來源回本（兩邊都是 0.1 年精度）。負值＝平台算得比實際快回本。

## 誤差原因（不藏）

1. **平台全面偏樂觀（10 筆中 9 筆算得比實際快回本）**：案例的「年省電費÷年節電」換算每度 3.40–4.11 元，全部低於平台預設 4.2 元。工廠在「工廠數據」填自己的平均電價後，這部分誤差就會消失。是否把預設電價下修，留給下一輪決定（見下）。
2. **短回本案例的百分比誤差被放大**：pc09 回本 0.3 年，差 0.1 年就是 33%；pc10 是 23%。兩筆都是食品業、24 小時運轉的設備，隱含電價最低（約 3.4–3.5 元/度）。
3. **這次沒有驗證節電量**：平台沒有「從改善前用電預測能省多少度」的模型，節電量是取自案例（相當於廠商報價寫的數字）。所以 0.20 年的誤差只代表「節電量→電費→回本」這段換算的準度，**不代表平台能預測一個改善案會省多少電**。
4. **樣本小而且集中**：10 筆只涵蓋照明、空壓機、冰水主機、空調、馬達變頻、泵浦風機；產業只有 3 類；其中 4 筆案例編號前段同為 B03、3 筆同為 B01，可能各自來自同一得獎單位。結論不能直接推到所有工廠。
5. **來源本身是申報值**：節能標竿獎的數字由得獎單位申報、能源署評選後公開，我們沒有實地查證。pc05、pc06 內文寫明有實測（綠基會性能檢測、前後各掛表 1 個月），其他筆沒寫量測方法。

## 節電量預測回測結論（目前無法回測／已知缺口）

- **檢查標的（空壓機公開案例 `pc03`、`pc04`）**：
  - 兩筆案例來源均**未揭露改善前與改善後用電量**（`beforeKwhPerYear = null`、`afterKwhPerYear = null`）。
  - `pc03`（`114-B03-112-UT02`）未載明空壓機設備總容量（kW／HP）與年運轉時數；`pc04`（`114-B03-113-UT01`）僅載明 `2 台 50 hp（約 74.6 kW）`，亦未載明運轉時數。
  - 若僅對 `pc04` 已揭露之實績數字做單位換算：`47,000 度/年 ÷ 74.6 kW ≈ 630 滿載當量小時/年`（此為已揭露實績之換算事實，非模型預測結果）。
- **回測結論**：**目前無法做節電預測回測**。平台現階段沒有「從改善前設備條件預測節電量或省電 %」的模型（屬於已知能力缺口），亦不對工廠端產生預測省電區間；空壓機區塊僅陳述「同類公開案例實績範圍」，實際節電量一律須待廠商場勘掛表實測並提供報價後方得試算。
- **後續安排**：本輪不為回測而臨時補建預測模型，待 `PROP-0007 4c`（找廠商工具包）完成後再由團隊與觀察者評估是否建立或維持「只收廠商實測報價」。

## 下一輪建議

- 預設電價 4.2 元/度是否改成依產業或依契約類型給值（例如以台電公開平均單價為準並附出處），屬產品細節，CEO 可在 L1 決定，但需先找到可引用的出處。
- 要驗證「節電量」本身，需要案例同時寫改善前用電與設備條件（本次只有 3 筆有改善前後度數），可再找 113 年度以前或技術服務團的診斷案例集。
