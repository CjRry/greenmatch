## 3. 真人試用最可能扣分的 Top 8 問題（請 CEO 在 Round 2 優先修復）

1. **[嚴重・信任感扣分] `c04` 未得標廠商看得到得標對手的合約金額与工期（商業機密外洩）**
   - 以未得標廠商（恆壓空壓 `v02`）查看 `c04` 時，畫面顯示得標廠商的合約金額 `NT$ 265 萬` 與開工/完工日，甚至提示未得標廠商「提供合約與施工排程」。
   - **修法**：當案件已有 `selectedVendorId` 且當前登入廠商不是得標廠商時，隱藏合約金額與施工細節，並明確顯示「工廠已選擇其他廠商承接本案」。

2. **[嚴重・信任感扣分] `c02` 預約場勘時間顯示少 8 小時（UTC 時區 bug）**
   - 廠商選擇 `14:00` 預約場勘，活動紀錄卻顯示 `06:00`（`datetime-local` 轉 ISO / 顯示時造成 UTC -8h 落差）。
   - **修法**：統一以台灣本地時間解析與格式化 `datetime-local` 字串，並加單元測試驗證。

3. **[高・對廠商有用扣分] 台中/中部在需求市集開放中需求為 0 筆，且需求表缺運轉時數／現場照片或場勘前追問**
   - 台中是台灣機械與金屬加工重鎮，廠商篩選「中部」或「台中市」看到 0 筆開放需求會覺得平台沒案源。
   - **修法**：在 seed `needs.ts` 確保北、中、南皆有開放中（stage 2 `assess`）的示範需求，並在需求詳情頁顯示工廠已提供的馬力 kW、契約容量與待確認問題。

4. **[高・看得懂扣分] 廠商工作台 `/#/me` 狀態統計數字與下方列表筆數對不起來**
   - 階段 4「已送出報價（待工廠決定）」、階段 5「簽約」、階段 8「用電比較」在廠商端指標卡被遺漏或歸類不清。
   - **修法**：檢查 `src/features/workspace/lib/views.ts` 與 `Hub.tsx` 的廠商狀態分桶，讓所有進行中案件都能對應到清楚的狀態標籤。

5. **[中・看得懂扣分] `c10`（階段 2）與 `c01`（階段 4）在廠商視角的提示語與按鈕狀態矛盾**
   - `c01` 綠能節電明明已送過報價，但上方仍寫「廠商提出改善方案與報價」且按鈕顯示「我已送出報價」disabled，未清楚寫「你已送出報價（NT$ 186 萬），等待工廠比較與選擇」。

6. **[中・手機視覺扣分] 375px 手機版首屏同時出現 3 個「試用回饋」入口且 Header 按鈕折成兩行**
   - Header、TrialGuideBar、Bottom Nav 同時顯示回饋按鈕，在 375px 小螢幕略顯擁擠。
   - **修法**：375px 時精簡 Header 動作按鈕文字或將次要入口收斂，確保單行不折行。

7. **[中・技術品質] React Console Warning（未掛載元件 state 更新）**
   - 首頁載入時 Console 出現 `Can't perform a React state update on a component that hasn't mounted yet... Move this work to useEffect instead.`（可能來自 store hook 或 `useSession` / `useStoreInfo` 初始化）。

8. **[中・工廠信任感] 推薦分數與補助金額旁的「為什麼這樣算」還能更直覺**
   - 工廠老闆看到「推薦分數 81.1」會想知道為什麼是這 2 家而不是廣告買榜：可在推薦卡片直接用一句白話強調「平台不收廣告費排名・依專長、距離、評價與規模契合度計算」。
