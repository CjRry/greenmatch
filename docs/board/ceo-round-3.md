# CEO Round 3 Plan — 綠媒 GreenMatch

**時間**：2026-11-13 Round 3（接續 Round 2 `@factory-persona` 複查 `#33` 與程式碼巡檢）
**目標**：消除手機比價橫滑、責任文字矛盾、未公告補助金額誤解與文字一致化，讓工廠與廠商體驗再往 90+ 分與穩定 NPS 推進。

---

## 本輪處理項目（對應 `@factory-persona` Round 2 `#33` 與巡檢發現）

1. **`#/cases/:id/quotes` 報價比較表（`QuoteCompare.tsx`）手機並排與繁簡錯字修正**
   - 修正價差提醒文字簡體錯字：`修補与舊機拆除` → `修補與舊機拆除`。
   - 手機版（`<640px`）將比較表各列自動轉為兩欄等寬並排卡片（上方為項目名稱，下方左右並列兩家廠商與金額），免除在 `<ScrollX>` 內左右橫滑才能看右欄（如「府城機電」）的困擾；桌面版（`sm:` 以上）與列印版維持標準多欄比較表。

2. **`#/me`「待你處理」與「我的案件」責任文字統一（`Hub.tsx`、`CaseRow.tsx`）**
   - 當 `c01` 等報價階段案件受邀廠商皆已報價時，在 `CaseRow` 傳入 `handlerOverride="目前輪到工廠決定"`，避免卡片上同時出現「目前由廠商處理」與黃底標籤「2 家已報價・待貴廠決定」的自相矛盾。

3. **補助標示與分類準確化（`Subsidy.tsx`、`subsidies/index.ts`、`NeedWizard.tsx`）**
   - 區分 `relayed` 來源標籤：`power-equipment` 維持「經銷商參考區間」，環境部碳費基金補助與貸款（`moenv-grant`、`moenv-loan`）改為「政策參考／待開辦」，不再誤貼經銷商標籤。
   - 未公告之 `moenv-grant`（溫室氣體減量技術及氣候變遷調適補助）金額註記由「最高約 NT$ 125 萬（待公告）」改為「上限 50%（依預算約 NT$ 125 萬，待公告）」，避免訪客誤以為 125 萬為已核定現金。
   - `NeedWizard.tsx` 第 3 步 `<SubsidyCard>` 同步補上行內 `契約容量 kW` 快速試算 ESCO 輸入框。

4. **`#/feedback` 文案一致化與手機自動捲動引導（`Feedback.tsx`）**
   - 開頭說明統一為「點選分數即可直接線上送出」，第 5 區說明與按鈕名稱統一為「送出回饋（免開信箱）」。
   - 未選評分就點擊送出時，除按鈕旁明確紅字提示外，自動平滑捲動至第一個未作答題目（`#rubric-*` 或 `#feedback-nps`），手機填寫零迷路。

5. **碳盤查熱點帶入設備＆場勘時間時區測試（`CarbonDashboard.tsx`、`transitions.test.ts`）**
   - `CarbonDashboard.tsx` 熱點按鈕帶入 `?equip=` 參數預填 `NeedWizard`；補齊 `schedule_survey` 本地時間格式化單元測試。

6. **節能廠商體驗與案源精準度升級（對應 `#36` `@vendor-persona` Round 2 稽核）**
   - **報價解析＆商務條件（`QuoteSubmit.tsx`）**：改採逐行貨幣解析並修復含千分位逗號與「合計 - 施工費」之設備金額萃取，同時支援「約 XX 個月回本」格式；新增選填之「報價有效天數」「預估停機施工天數」「付款條件摘要」，有填寫時附加 `[商務條件補充]` 供工廠比價參考。
   - **廠商案件工作台分頁（`Hub.tsx`）**：新增條件式分頁「已報價待決定」與「已結案／未得標」，讓廠商在送出報價（`c01`）或未得標後仍能清楚追蹤去向，不再誤以為案件消失。
   - **智慧配對核心工項門檻（`filters.ts`）**：若需求包含非 `ems` 之核心節能設備（如空壓、冰水、鍋爐等），廠商至少須具備其中一項核心工項專長才列入推薦，避免僅靠 `ems` 標籤跨界錯配。
   - **階段狀態與時間軸清楚化（`StageActions.tsx`、`Timeline.tsx`、`CaseTracker.tsx`）**：第 2 階段非負責人（如廠商看 `c10`）移除無效置灰按鈕，改為清楚狀態提示與「先查看完整需求規格（可預先提問） →」連結；未得標廠商檢視案件時間軸時，不再誤顯示「廠商負責：提供合約與施工排程」，改顯示「後續階段將由得標廠商與工廠共同執行」。
   - **表格排版、公開入口導流與廠商承諾（`NeedDetail.tsx`、`routes.tsx`、`Landing.tsx`）**：`標準需求表` 表頭補上 `whitespace-nowrap` 防止「數量」折行；補齊 `/vendors/new` 與 `/factories/new` 導向註冊頁；首頁補上「給節能廠商／ESCO 的三個承諾：不搶標、不白跑、免平台抽成」卡片。
