## 二、Round 3 → Round 4 熱修實測驗證結果

1. **`QuoteSubmit` 千分位貨幣與多行報價擷取修復（`#/cases/c01/quote/new`、`#/cases/c02/quote/new`）**
   - **案例一（`c01` 預設多行報價單）**：內文含 `1. 37kW 永磁變頻螺旋式空壓機 ×3 NT$ 1,860,000`、`2. 空壓管路洩漏檢測與修補 NT$ 85,000`、`3. 安裝、配管、配電工資 NT$ 210,000`、`4. 空調溫控與排程控制器 ×6 NT$ 96,000`、`合計（未稅）NT$ 2,251,000`、`約 45 個月回本`。點擊 `從上方文字重新擷取數字` 後：
     - `設備費（未稅・元）` = **`2041000`**（精準等於 `2,251,000 - 210,000`）
     - `施工費（未稅・元）` = **`210000`**（已不再截成 `210`）
     - `保固年限` = **`3`**、`預估每月省電` = **`11000`**、`節電百分比` = **`20`**、`回本月數` = **`45`**
   - **案例二（`c02` 推進場勘完成 → 提交多行新報價）**：貼入 `1. 永磁變頻空壓機 15kW ×2 台 NT$ 980,000`、`2. 乾燥機與儲氣桶 NT$ 120,000`、`3. 安裝配管配電工資 NT$ 160,000`、`合計（未稅）NT$ 1,260,000`、`約 38 個月回本`、`基準期：2025年6-8月`，擷取結果：
     - `設備費（未稅・元）` = **`1100000`**（精準等於 `1,260,000 - 160,000`）
     - `施工費（未稅・元）` = **`160000`**、`回本月數` = **`38`**、`比較基準期間` = **`2025年6-8月`**
   - **案例三（`c02` 改測明確關鍵字報價）**：貼入 `設備費 NT$ 1,680,000，施工費 NT$ 240,000... 約 36 個月回本。基準期：2025年7-9月。`，擷取結果：
