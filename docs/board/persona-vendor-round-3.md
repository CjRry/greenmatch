## 二、Round 2 → Round 3 已驗證修復清單

1. **首頁補上「給節能廠商／ESCO 的三個承諾」（`#/`)**
   - Hero 下方新增專屬卡片：「給節能廠商／ESCO 的三個承諾：不搶標、不白跑、免平台抽成」，並提供 `廠商看開放案源` 入口，進站即可看懂對廠商的保障機制。
2. **核心專長門檻生效，不再跨區誤標太陽能案（`#/needs`）**
   - 以 `綠能節電`（台南、空壓機／空調／馬達／EMS）瀏覽 7 筆需求時，新竹縣 `屋頂太陽能自發自用與產線用電監測`（`300 kW` 太陽能＋EMS）已**不再**顯示 `符合你的專長（跨區案源）`；僅 `染整廠冷卻水塔泵浦與排風機變頻改善`、`CNC 產線空壓機 2 台汰換與管路抓漏`、`老舊空壓機汰換` 正確標記符合專長。
3. **廠商工作台補齊「已報價待決定」與「已結案／未得標」分頁（`#/me`）**
   - `綠能節電` 顯示 `已報價待決定 1` 分頁，點選可篩出 `c01`（`空壓機 3 台汰換與空調節能`）。
   - `恆壓空壓系統` 顯示 `已結案／未得標 1` 分頁，不再讓廠商面對 6 個 `0` 卻不知案子去哪。
4. **Stage 2 `#/cases/c10` 移除 disabled 按鈕**
   - `你可以做的事` 已無置灰的 `查看推薦廠商` 按鈕，改為明確說明「你已被平台推薦給工廠，目前等待工廠確認邀請場勘（每案最多推薦 2 家，無須競標）」，並附 `先查看完整需求規格（可預先提問） →` 連結。
5. **未得標案件時間軸文案修正（`#/cases/c04`）**
   - 切換為 `恆壓空壓系統` 檢視 `#/cases/c04` 時，階段 5–8 改為顯示「後續階段將由得標廠商與工廠共同執行。」，不再出現「廠商負責：提供合約與施工排程」，且得標金額與時程維持隱藏。
6. **報價回本月數自動擷取＋新增商務選填欄位（`#/cases/c01/quote/new`、`#/cases/c02/quote/new`）**
   - `約 45 個月回本` 正確填入 `回本月數（個月）= 45`；`c02` 貼上 `約 38 個月回本` 與 `基準期：2025年6-8月` 亦正確填入 `38` 與 `2025年6-8月`。
   - 新增 `報價有效天數（選填）`、`預估停機施工天數（選填）`、`付款條件摘要（選填）` 三個實務欄位。
7. **入口導轉、回饋頁文案與手機表格單行修正**
   - `#/vendors/new` 實測正確導轉至 `#/register?role=vendor`（`登錄節能廠商`），不再顯示 `找不到這家廠商`。
   - `#/feedback` 頂部副標改為「點選分數即可直接線上送出」，與下方 `送出回饋（免開信箱）` 一致；未評分直接按送出會自動捲動並跳出具體缺項提示。
   - `375px` 手機實測 `#/needs/n14` 表頭 `數量` 不再折成直排（`height: 36.5px`），7 頁皆 `overflowX: false`、Console `0` 錯誤。
