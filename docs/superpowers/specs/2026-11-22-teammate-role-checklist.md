# 隊友角色：批准前須知與事項

日期：2026-11-22｜搭配文件：[隊友角色：設計（第 2 版）](2026-11-22-teammate-role-design.md)

## 你要批准的是什麼

讓隊友用他自己的 Claude Code 參與綠媒。網站規劃與設計這類小事，他做完由 CEO 檢查後合併，不用問你。綠媒的運作模式、管理架構、工作模式這類大方向，他只能寫請求單，要你批准才執行。

批准的是「開始做這套機制」。批准後，隊友還不會馬上拿到任何東西，邀請他是最後一步，由你親手按。

## 批准後會發生什麼

1. 我寫實作計畫，接著做檔案、指令、檢查程式與測試，跑 `npm run check`。
2. 做完後 commit 到目前的分支，並給你看結果。
3. 你邀請一位隊友，先用他的帳號完整試一次流程。
4. 試過沒問題，才正式開始用。

## 批准後不會發生的事

- 不會自動推送到 GitHub，不會邀請任何人。這兩件都等你自己做。
- 不會改綠媒網站的任何畫面或功能。
- 不會花錢，不會升級 GitHub 方案。

## 你要知道的事

### 隊友會看到什麼

隊友拿到的是整個 repo，**全部內容都看得到**，不只是網站程式。包括：

- 治理文件：董事會協議、提案、觀察報告、`STATUS.md`。
- 頻道紀錄 `channel.jsonl`：Fable、Argon、CEO 之間的所有對話。
- `docs/board/` 的過往紀錄，例如試用回饋評分、寄信模板。
- **你的 Gmail 地址**：出現在 10 個左右的檔案裡（例如 `STATUS.md`、`TEAM.md`、`human-scores.md`、`outreach-template.md`），也出現在每一筆 commit 的作者欄。

### 個資檢查結果（我已經查過）

| 項目 | 結果 |
|---|---|
| 外寄名單（收件人信箱、公司聯絡人） | 從來沒有進過版本控制，`.gitignore` 有擋，隊友看不到 |
| 試用回饋原始資料 `live-feedback.jsonl` | 同上，不在版本控制內 |
| 示範資料裡的信箱 | 都是 `.example` 結尾的假信箱 |
| 你的 Gmail | **在**。檔案裡的可以替換，commit 作者欄的要改寫歷史才能去掉，不建議 |
| 電話號碼 | 沒有找到 |

### 已知的限制與風險

- **小事不是即時合併**：要等你下一次開 CEO 工作。隊友在自己電腦上看得到自己的修改，不受影響。
- **合併前要在你電腦上跑隊友的測試**：等於執行他寫的程式。我會先讀改動並掃描危險寫法，但風險只能降低，不能消除。
- **隊友電腦上的護欄可以被他關掉**：真正的把關是「他沒有寫入權限，進主要版本一定要經過 CEO 的檢查程式」。
- **小事大事的分界靠路徑名單**：名單訂得太寬，大事可能被當成小事合併。拿不準時檢查程式會停下來問你。
- **隊友改的地方，可能也有工程師代理人在改**：CEO 合併時處理衝突。
- **隊友的 Claude 用量由隊友自己的帳號負擔。**

### 如果之後想收回

- 在 GitHub 移除協作者，他就看不到新的內容了。已經下載的舊版本收不回來。
- 只想暫停小事的自動合併：把 `teammate-paths.json` 的小事路徑清空，所有改動都會停下來問你。

## 批准前請你決定

每一項都有我的建議，你同意就不用改。

| # | 要決定的事 | 我的建議 |
|---|---|---|
| 1 | 設計文件的「小事／大事」表 | 照表 |
| 2 | 小事路徑名單（`src/ui`、`src/styles`、`src/app` 不含路由檔、各功能的 `pages` 與 `components`、`docs/design/`） | 照名單，用一陣子再調整 |
| 3 | 接受小事延遲合併，不升級 GitHub 付費方案 | 接受，之後覺得慢再升級 |
| 4 | 接受「合併前在你電腦上跑隊友的測試」這個風險 | 接受，隊友是你信任的人 |
| 5 | 你的 Gmail 出現在 repo 裡 | 接受。隊友是隊友，本來就知道你的聯絡方式。想清掉檔案裡的也可以，做實作時一起處理 |
| 6 | 隊友是誰、幾位 | 先邀一位試用，試過再加人 |

## 你要親手做的事（我不能代做）

1. **把程式推送到 GitHub**：隊友只看得到 GitHub 上的版本。目前本機的 `main` 比 GitHub 新了 7 筆以上（你之前說先不推），不推的話隊友拿到的是舊版。
2. **在 GitHub 邀請隊友**，權限選 **Read**。
3. **告訴我隊友的 GitHub 帳號名稱**，我加進名單。
4. **陪隊友試一次流程**：他送一個小改動和一份請求單，確認小事被合併、大事停下來等你。
